# After Sermon · 함께묵상

**Pray the week together**  
*From Sunday Word to daily prayer with your friends*

Help your Sunday Word guide the week — live it more fully to God with your friends and church.

Why we built it: [`PURPOSE.en.md`](./PURPOSE.en.md)  
Store listing: [`APP_STORE.md`](./APP_STORE.md)

---

## Who it’s for

- Cells and small groups who want to **live the week after the sermon** together
- Friends who want an **accountability buddy** across distance
- Anyone who keeps personal notes private but shares prayer and practice

---

## What you can do

| Flow | What it means |
| --- | --- |
| **Capture** | Save Sunday’s Word (private notes stay yours) |
| **Share** | Prayer, meditation point, and practice with the group |
| **Today** | Check in after prayer; send “I prayed” |
| **Together** | Invite code + season with your people |
| **Archive** | Look back on weeks with the Word |

---

## Stack

Next.js · React · TypeScript · Tailwind · Supabase · Google sign-in

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) → choose language → sign in → capture → group.

Setup: [`SETUP.md`](./SETUP.md)
